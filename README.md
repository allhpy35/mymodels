#Model_hwang

해당 repo는 내가 직접 만든 모델들의 어려 버전을 활용하여, 나중에 다시 사용하려고 만든 코드들이다. 
하나의 모델을 가지고 classification, regression, 를 풀 수 있는 것을 만들 것이다. 

우선 Final Model은 검증된 코드로 다시 재사용 할 수 있게 만들어 놓았다. 
Test Model은 모델을 수정하고 변경하는 장소이다. 

Utils는 해당 모델들을 불러오거나, 사용하기 좋은 Tool를 만드는 코드들이다. 

모든 코드는 main에서 불러와서 사용할 수 있게 할 것이다.
